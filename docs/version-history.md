# Version History

## V1

Established the evidence-boundary audit and readiness action plan. Testing exposed overly strict aggregate states and inconsistent handling of exploratory prototypes.

## V2.1 / V2.1.1

Added dual status dimensions, traceable Issue registries, consistency checks, and clearer designer decision markers. Testing improved structure but still produced too many severe Issues and sometimes paused an entire direction when only a proposed solution was unsupported.

## V2.2

Root-cause-first Issue generation, conflict-layer classification, counterfactual BLOCKER gating, solution-level pause semantics, and compact output were added. The three-case regression passed logically 9/9, with a separate runtime warning caused by network instability.
