# 已有分析

## 团队形成的洞察

1. 通知会破坏学生专注；
2. 关闭通知能提高效率；
3. 学生虽然可能短期焦虑，但长期会适应；
4. 默认关闭全部通知是最简单且最有效的方案。

## 目标用户

- 18–25 岁大学生；
- 经常使用手机；
- 需要完成较长学习或编程任务；
- 容易受到社交软件通知影响。

## 用户需求

团队写出的需求为：

> 学生需要在学习期间完全隔绝通知，避免被打断。

## 当前优先级

P0：

- 默认关闭全部通知；
- 不允许紧急联系人绕过；
- 学习结束后一次性展示摘要。

P1：

- 自定义通知白名单；
- 根据课程自动设置；
- 统计专注表现。
